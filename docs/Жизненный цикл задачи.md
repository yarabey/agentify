title: Жизненный цикл задачи

stateDiagram-v2  
    direction TB  
  
    [*] --> Created  
  
    Created: Создана  
    Queued: В очереди  
    Running: Выполняется  
    WaitingUser: Ожидает ответа пользователя  
    AwaitingConfirm: Ожидает подтверждения  
    Completed: Завершена  
    Failed: Провалена  
    Cancelled: Отменена  
    Stale: Зависла (таймаут)  
  
    Created --> Queued: помещена в очередь сообщений  
    Queued --> Running: машина забрала задачу  
  
    Running --> WaitingUser: агент задал вопрос / запросил согласование команды  
    WaitingUser --> Running: пользователь ответил / согласовал  
  
    Running --> AwaitingConfirm: агент сообщил о завершении  
    AwaitingConfirm --> Completed: пользователь явно подтвердил  
    AwaitingConfirm --> Running: пользователь отклонил → доработка  
  
    Running --> Failed: ошибка агента или машины  
  
    Running --> Stale: машина пропала надолго (таймаут)  
    WaitingUser --> Stale: машина пропала надолго (таймаут)  
    Stale --> Running: машина вернулась → продолжение  
  
    Queued --> Cancelled: отмена пользователем  
    Running --> Cancelled: отмена (безопасно)  
    WaitingUser --> Cancelled: отмена  
    AwaitingConfirm --> Cancelled: отмена  
    Stale --> Cancelled: отмена  
  
    Completed --> [*]  
    Failed --> [*]  
    Cancelled --> [*]  
  
    note right of Queued  
        Если машина оффлайн — задача  
        ждёт в очереди и доставляется,  
        когда машина снова онлайн.  
        Ничего не теряется.  
    end note  
  
    note right of AwaitingConfirm  
        «Агент сообщил о завершении» — НЕ  
        закрывает задачу. Закрывает только  
        явное подтверждение пользователя.  
        (Фаза 2: мягкие напоминания, если  
        долго нет подтверждения.)  
    end note  
  
    note left of Cancelled  
        Приоритет при отмене — сохранность  
        данных: критическая операция  
        доводится до безопасного состояния.  
    end note
